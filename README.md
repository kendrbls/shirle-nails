## Sobre el proyecto

Sitio de una sola página desarrollado para una manicurista que atiende en su
propio salón. El objetivo era ofrecerle presencia en línea para mostrar su
trabajo, sus precios y su ubicación, con un diseño acorde al rubro: cálido,
elegante y minimalista, en tonos crema.

Construido con **HTML, CSS y JavaScript puro**, sin frameworks, y publicado
gratis con **GitHub Pages**.

## Características

- Diseño responsive, adaptado a celular, tablet y escritorio
- Sección de servicios y precios en colones costarricenses (₡)
- Galería de trabajos
- Mapa de ubicación integrado con Google Maps
- Enlaces directos a WhatsApp e Instagram para reservar citas
- Menú de navegación con scroll suave y versión móvil

## Tecnologías

- HTML5 semántico
- CSS3 (Grid, Flexbox, variables CSS)
- JavaScript (vanilla, sin dependencias)
- Google Fonts (Cormorant Garamond, Jost)
- GitHub Pages para el despliegue

## Estructura del proyecto

```
shirle-nails/
├── index.html          # Estructura y contenido del sitio
├── css/style.css        # Estilos y diseño visual
├── js/script.js          # Menú móvil, mapa y funciones dinámicas
└── assets/
    ├── img/               # Fotos de portada y perfil
    └── gallery/            # Fotos de trabajos
```
